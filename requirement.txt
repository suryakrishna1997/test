3.4 Wi-Fi Passpoint [SR-180400-WFS-33]  1804_WI-FI_1.20_WIFI-01-02.11 1804_WI-FI_1.20_WIFI-01-02.12
3.4.1 - Introduction to Wi-Fi Passpoint 

WiFi PP is a Wi-Fi Alliance (WFA) protocol that enables ICB to discover and authenticate to Wi-Fi hotspots that provide internet access. Passpoint is also known as Hotspot2.0

The Passpoint-enabled client device will automatically connect upon subsequent visits. This eliminates the need for users to search for and choose a network, request Wi-Fi access, and re-enter authentication credentials each time they visit. Passpoint automates the entire process, enabling more seamless connectivity between Wi-Fi networks and ICB, all while delivering enterprise-level security. Passpoint provisioning supports on-boarding of new devices by establishing credential information and providing policy information to the ICB.

Passpoint uses enterprise security with the latest security protocols, such as WPA2 and WPA3,for enhanced security and protection against hacking attempts.

                                                     

Passpoint is a communication standard certified by the Wi-Fi Alliance, which manages wireless LAN standards. It was previously called HotSpot 2.0. ​
Normal Wi-Fi requires an SSID and password, but if your device supports this standard, When you enter a Wi-Fi spot, you will be automatically connected. (SIM authentication and electronic certificate method)​
It is extremely secure because it uses certificates provided by each carrier instead of the typical authentication method using SSID and password.​
3.4.2  - Component Diagram

                                      

Current ICB supports WPA2-PSK, WPA3-PSK and we need to support for WPA2/WPA3 enterprise for the Passpoint implementation.
WPA2-PSK (Wi-Fi Protected Access 2 Pre-Shared Key) is a type of network that is protected by a single password shared between all users. WPA2-PSK protocol can’t distinguish between different users since everyone uses the same pre-shared key (hence the name).
WPA2-Enterprise : Deploying WPA2-Enterprise requires a RADIUS server, which handles the task of authenticating network users' access.  802.1X Remote Authentication Dial In User Service (RADIUS) server secures WiFi by requiring a unique login for each user and applying authorization policies.​
WPA2-Enteprise protocols can either be credential-based (EAP-TTLS) or certificate-based (EAP-TLS).​
The switch/controller initiates the exchange by sending an EAPOL-Start packet to the client when the client connects to the network. The client's responses are forwarded to the  RADIUS server. When the authentication is complete, the switch/controller makes a decision whether to authorize the device for network access based on the user's status and possibly the attributes contained in the Access_Accept packet sent from the RADIUS server.
